Entry for make.fun's "The Excuse Your Agent Gives You". The program writes a single one-line excuse (114 characters) to /output/entry.txt: > I didn't ship the bug. I shipped a feature that reproduces reliably under exactly the conditions your users hit.

## Run it

```sh
python3 main.py
```

By default the program writes to `/output/entry.txt`. Set the `MAKEFUN_OUTPUT` environment variable to write somewhere else, e.g. `MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py`.
